git diff отличается от git show и git log тем, что git diff показывает изменения до git add, git show показывает информацию об одном коммите, а git log выводит список коммитов зафиксированных в репозитории.

log -S ищет коммиты, в которых были изменения с указанным в команде словом.blame построчно показывает в каком коммите она изменилась и кто её изменил.

git restore используется до применения git add и откатывает файл до состояния последнего коммита, а git restore --source==... возвращает файл к состоянию выбранного коммита.

git reset --hard отличается от revert тем, что первый откатывает состояние к указанному коммиту и безвозвратно удаляет незакоммиченные изменения, а git revert создает новый коммит, в котором делает изменения обратные последнему коммиту.

git tag отличается от ветки тем, что тэг указывает на конкретный коммит, а ветка это новый указатель на конкретный коммит.
