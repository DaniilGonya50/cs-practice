Рабочая папка - это папка, где хранятся файлы и пользователь редактирует их.

Индекс - это сбор изменений, которые в последствии попадут в комит.

Комит - это сохраненные, закомментированные изменения проекта.

Различие гит и гитхаб. Гит - это система контроля версий, которая позволяет отслеживать изменения в коде, возвращаться к прошлым версиям и работать над проектом в команде. ГитХаб - это облачная платформа, на которой хранят код,к которому можно получить доступ с других пк.

Использованные команды:
git status - показывает текущее состояния репозитория.
git diff - показывает, что изменилось строка за строкой, сравнивая с тем, что было до.
git diff --staged - это изменения, которые готовы к коммиту.
